# 결과 — DINO와 가장 비슷하게 판단하는 모델

**2026-08-10 측정.** 표본 300쌍 + 검산쌍 20쌍. A40, 전 과정 재현 가능.

---

## 결론

**SigLIP ViT-B/16 (`vit_base_patch16_siglip_224`)** 이 DINO와 가장 비슷하게 판단합니다.

```
모델            Pearson   Spearman    부트스트랩 1위비율
siglip_b16       0.6341     0.5346          91.9%      ← 1위
clip_b16         0.5723     0.4683           4.7%
clip_l14         0.5655     0.4819           3.5%
mae_b16          0.0859     0.1095           0.0%
```

**세 가지 독립 검사가 모두 SigLIP을 92% 안팎으로 지목합니다.**

| 검사 | SigLIP 1위 비율 |
|---|---|
| 전체 부트스트랩 10,000회 | 91.9% |
| 반쪽 나누기 2,000회 | 91.8% (두 절반이 일치한 비율 83.7%) |
| 가장 닮은 구간 Q1 부트스트랩 | 92.1% |

---

## 정직하게 짚어야 할 것 세 가지

### ① 1위와 2위의 차이는 통계적으로 확정되지 않았습니다

```
siglip_b16 − clip_b16 = 0.0619
95% 신뢰구간 [−0.0120, 0.1354]      ← 0을 포함
0보다 클 확률 94.8%                  ← 통상 기준선 95%에 근소하게 미달
```

**세 검사가 일관되게 92%로 SigLIP을 지목하므로 실무 판단으로는 충분하지만, "통계적으로 유의하게 앞선다"고 말할 수는 없습니다.** 확정하려면 표본을 약 4배(1,200쌍)로 늘려야 합니다.

### ② 어떤 모델도 DINO를 잘 따라가지 못합니다

1위조차 **r = 0.63**입니다. 대체재가 아니라 "그나마 가장 나은 것"입니다. 로스로 쓸 때 이 점을 감안해야 합니다.

### ③ 큰 모델이 낫지 않았습니다

```
CLIP ViT-L/14 (304M)   0.5655
CLIP ViT-B/16 (86M)    0.5723    ← 오히려 미세하게 앞섬
```

둘은 사실상 구분되지 않습니다. **DINO를 흉내내는 데는 모델 크기가 도움이 안 됩니다.**

---

## 실제로 쓸 구간에서는 SigLIP이 더 앞섭니다

예측-정답 비교는 **유사도가 높은 구간**에서 일어납니다. DINO 거리 하위 25%(가장 닮은 75쌍)만 떼어 보면:

```
siglip_b16   0.6887      ← 전체(0.6341)보다 높아짐
clip_b16     0.5962
clip_l14     0.5590
mae_b16      0.2161
```

**격차가 0.062에서 0.093으로 벌어집니다.** 실사용 구간에서 SigLIP이 더 유리하다는 뜻입니다.

전 구간 표를 보면 중간 구간(Q2·Q3)에서는 모든 모델이 0 근처로 무너집니다. 사분위로 자르면 값 범위가 좁아져 상관계수가 기계적으로 낮아지는 영향이 크므로, **Q2·Q3 붕괴 자체를 결함으로 읽지는 말아야 합니다.** 중요한 건 Q1에서 순위가 유지된다는 점입니다.

```
모델          Q1(가장 닮음)      Q2        Q3    Q4(가장 다름)
siglip_b16        0.6887   -0.0528    0.0599     0.2828
clip_b16          0.5962    0.1218    0.0168     0.4053
clip_l14          0.5590    0.2095    0.0833     0.3621
mae_b16           0.2161    0.0677   -0.1037     0.1082
```

## MAE는 명확히 탈락입니다

```
r = 0.0859,  95%CI [−0.0170, 0.1909]      ← 0을 포함. 무관과 구분 안 됨
모든 검사에서 1위 비율 0.0%
```

원인이 유사도 분포에 그대로 보입니다.

```
모델          유사도 범위          표준편차
dino         0.008 ~ 1.000        0.2266
clip_l14     0.373 ~ 1.000        0.1303
clip_b16     0.373 ~ 1.000        0.1208
siglip_b16   0.570 ~ 1.000        0.0845
mae_b16      0.820 ~ 1.000        0.0249   ← DINO의 1/9
```

**MAE는 서로 무관한 그림들에도 전부 "0.82 이상 비슷하다"고 답합니다.** 복원(reconstruction)으로 학습된 모델이라 파인튜닝 없이는 특징 공간이 판별용으로 안 나오는 알려진 성질입니다.

⚠ **표준편차 차이는 로스로 쓸 때 중요합니다.** SigLIP은 DINO 대비 값 범위가 3분의 1로 눌려 있어, 같은 크기의 화질 차이가 만드는 로스 변화량이 작습니다. 가중치를 조정해야 할 수 있습니다.

## 측정 조건 (재현용)

```
쌍            train 영상 11,132개(약 100만 프레임)에서 전부 무작위로 300쌍
              + 검산용 동일쌍 20쌍

정규화        각 모델 자기 pretrained_cfg 값
특징          timm num_classes=0 의 풀링 출력
```

## 통과한 검증 (전부 자동, 실패 시 즉시 중단)

```
채점기 원본 함수와 재구현의 출력 차이     0.000e+00   (A~F, 32가지 경우)
DINO 실물 특징값이 채점기 경로와 동일      0.000e+00   (G)
같은 그림끼리 코사인 거리 0               모든 모델 < 5e-7
두 번 돌려 같은 값                        모든 모델 0.000e+00
DINO 대 DINO 상관계수                     1.0000000000
DINO 거리 범위                            0.074 ~ 0.992 (폭 0.918, 충분히 넓음)
봉우리 계수                               0.402 (단봉, 상관계수 부풀림 없음)
gt/pred 파일명 일치, 전부 320x512         통과
```

**봉우리 계수 0.402가 특히 중요합니다.** 무작위 짝짓기는 분포가 봉우리 두 개가 되어 상관계수가 부풀려지는 함정이 있는데, 실측 결과 단봉이라 그 함정에 빠지지 않았습니다.

## 남은 선택지

**표본을 1,200쌍으로 늘리면** 1위-2위 차이가 통계적으로 확정됩니다. EU-SE-1 리전 포드를 10분 정도 다시 띄워 쌍만 더 만들면 되고, 특징 추출은 GPU에서 모델당 1분입니다.

지금 결론(SigLIP)이 바뀔 가능성은 낮습니다 — 세 검사가 모두 92%로 일치하므로 뒤집히려면 8% 쪽이 나와야 합니다.

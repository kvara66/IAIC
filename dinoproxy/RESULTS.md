**중요한 발견 — 실제 상황에서 훨씬 잘 맞습니다.** 무관한 사진끼리 비교했을 때는 0.63이었는데, 실제로 채점기가 보는 분포(같은 장면의 정답 vs 예측)에서는 **0.80~0.85**입니다. 처음 실험이 오히려 과소평가였습니다.

| 실험 | 무엇을 비교하나 |
|---|---|
| 1 | train 영상 100만 장에서 무작위 두 장 (서로 무관) |
| A | 홀드아웃 정답 영상 vs 같은 장면의 우리 생성물. **채점기가 하는 것과 완전히 동일** |
| B | 같은 장면을 다른 설정으로 만든 우리 생성물끼리 |
| B+ | B를 4배로. 설정 4벌(ck667·g25·g10s50·static) 전 조합, 214장면 |

A는 정답 npy가 20개뿐이라 독립 군집이 20개입니다. 그래서 프레임 320개여도 실질 표본이 작아 확정에 못 씁니다. **B+가 확정의 근거입니다.**

### ⚠ 유일한 예외와 그 이유

정규화 상수를 전부 ImageNet으로 강제하면 SigLIP이 3위로 밀립니다. **이건 SigLIP에 학습 때 안 쓴 입력을 주는 것**이라 판단력이 아니라 붕괴를 재는 셈입니다.

```
SigLIP 학습 상수   (0.5, 0.5, 0.5)
ImageNet 상수      (0.485, 0.456, 0.406) / (0.229, 0.224, 0.225)

강제했을 때 변화
  clip_b16   .5723 → .5725   차이 0.0002    CLIP 상수가 ImageNet 과 거의 같아서 영향 없음
  clip_l14   .5655 → .5827   차이 0.0172
  siglip     .6341 → .2488   차이 0.3853    ← 혼자만 붕괴
```

**🔴 팀 전달 필수: SigLIP을 쓸 때는 반드시 `mean=std=(0.5,0.5,0.5)`를 써야 합니다.** ImageNet 상수를 먹이면 성능이 40% 수준으로 떨어집니다.

## 리사이즈 로직 (재구현 근거)

두 단계 모두 **비율 유지 + 중앙 정렬 + `value=0.0` 검은 패딩**. 어디서도 늘리거나 찌그러뜨리지 않습니다.

```
원본 480×640 (비율 0.750)
  1단계 → 내용 320×427 + 좌우 여백 42/43 = 320×512     비율 0.749
  2단계 → DINO 518    : 내용 324×432                    비율 0.750
          후보 224    : 내용 140×187                    비율 0.749
```

**후보 모델도 같은 함수를 쓰고 `size` 인자만 다릅니다.** 실측 확인:

```
dino     size=518   내용 324행이 97~421 에 중앙 배치   여백 정확히 0.0
clip_b16 size=224   내용 140행이  42~182 에 중앙 배치   여백 정확히 0.0
정규화 후 여백값도 (0−mean)/std 와 일치 (dino −2.1179, clip −1.7923)
```

해상도 차이(DINO는 324×432, 후보는 140×187)는 각 모델의 입력 크기 때문입니다. 이것도 검증했습니다 — **해상도를 맞춰도, 후보를 518로 올려도 순위가 같습니다.** 참고로 `DINO@518 vs DINO@224 = 0.8396` 이라, 같은 모델도 해상도를 바꾸면 이만큼 달라집니다.

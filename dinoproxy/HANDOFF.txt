================================================================
결론
================================================================

SigLIP ViT-B/16 이 채점기의 DINO 와 가장 비슷하게 판단합니다.

후보 4개 비교 결과 (실제 채점 상황을 흉내낸 1,200쌍 기준)

    모델              상관계수 r     설명력      순서일치율
    SigLIP ViT-B/16     0.8358      70%         83.6%      <- 1위
    CLIP ViT-B/16       0.7559      57%         80.7%
    CLIP ViT-L/14       0.7060      50%         77.7%
    MAE ViT-B/16        0.4720      22%         74.4%

순서일치율 = 두 쌍을 골라 "어느 쪽이 더 닮았나" 물었을 때 DINO 와 같은 답을 낼 확률
             (동전 던지기 50%, 완전 일치 100%)

통계적으로 확정됐습니다.
    장면 단위 부트스트랩 10,000회에서 SigLIP 1위 비율 100%
    1위와 2위 차이 0.0800, 95% 신뢰구간 [0.0512, 0.1090] 으로 0 을 넘지 않음


================================================================
바로 쓰실 설정 - 이대로 쓰셔야 합니다
================================================================

    timm 이름     vit_base_patch16_siglip_224
    입력 크기     224 x 224
    정규화        mean = (0.5, 0.5, 0.5)
                  std  = (0.5, 0.5, 0.5)
    특징          timm.create_model(name, pretrained=True, num_classes=0) 의 출력
                  768 차원
    라이선스      공개 사전학습 모델. 대회 규정이 명시적으로 허용


*** 가장 중요한 주의사항 ***

정규화 상수를 ImageNet 것으로 쓰면 성능이 절반 이하로 떨어집니다.

    자기 상수 (0.5, 0.5, 0.5) 사용      상관계수 0.6341
    ImageNet 상수 강제                   상관계수 0.2488

이건 SigLIP 이 학습 때 쓴 적 없는 입력을 주는 것이라 모델이 무너지는 겁니다.
저희가 검사한 10가지 조건 중에서 모델 순위가 뒤집히는 유일한 경우였습니다.

참고로 CLIP 은 자기 상수가 ImageNet 과 거의 같아서 영향이 없습니다
(0.5723 -> 0.5725). SigLIP 만 다릅니다.


================================================================
전처리 - 채점기와 똑같이 맞춰야 합니다
================================================================

채점기는 리사이즈를 두 번 합니다. 둘 다 비율을 유지하고 남는 곳을 검게 채웁니다.
어디서도 늘리거나 찌그러뜨리지 않습니다.

    원본 480x640 (비율 0.750)
      1단계 -> 내용 320x427 + 좌우 검은 여백 42/43 = 320x512    비율 0.749
      2단계 -> DINO 518    : 내용 324x432                       비율 0.750
               SigLIP 224  : 내용 140x187                       비율 0.749

각 단계 공식

    scale = min(목표높이/입력높이, 목표너비/입력너비)
    bilinear 로 리사이즈 (align_corners=False)
    남는 곳을 중앙 정렬로 0.0 패딩

주의: 2단계는 [0,1] 공간에서 0 으로 패딩한 "뒤에" 정규화합니다.
      순서를 바꾸면 검은 여백 값이 (0-mean)/std 가 아니라 0 이 되어 값이 달라집니다.

채점기 기본값은 target 320x512, pad=True 입니다.


================================================================
참고 - 채점기 DINO 의 실체
================================================================

조사하다 알게 된 것들입니다.

1. 채점기의 DINO 는 킷 내부 체크포인트가 아닙니다.
   timm 에서 공개 가중치를 받아 씁니다.

       모델명   vit_small_patch14_dinov2.lvd142m
       호출     timm.create_model(name, pretrained=True, num_classes=0)
       라이선스 Apache 2.0

   킷 안에 실제로 들어 있는 체크포인트는 action_extractor.ckpt 하나뿐입니다.

2. DINO 의 입력 크기는 224 가 아니라 518 입니다.
   채점기가 requested_size=0 을 넘기면 모델 기본값(518)이 쓰입니다.
   특징은 CLS 토큰 384 차원입니다.

3. DINO 는 화면의 절반 가까이를 검은 여백으로 봅니다.
   480x640 원본 기준 최종 내용 면적이 52% 입니다.

================================================================
쓰실 때 알아두셔야 할 한계
================================================================

1. SigLIP 은 DINO 판단의 70% 를 따라갑니다. 30% 는 못 따라갑니다.
   대체재로 쓸 만하지만 같은 것은 아닙니다.

2. SigLIP 의 유사도 값 범위가 DINO 보다 훨씬 좁습니다.

       DINO    유사도 범위 0.33 ~ 0.99   표준편차 0.152
       SigLIP  유사도 범위 0.77 ~ 1.00   표준편차 0.046

   같은 크기의 화질 차이가 만드는 로스 변화량이 3분의 1 수준입니다.
   로스에 붙이실 때 가중치를 그만큼 키워야 할 수 있습니다.

3. MAE 는 쓰지 마세요. 서로 다른 그림에도 전부 0.98 이상 비슷하다고 답합니다.
   복원으로 학습된 모델이라 파인튜닝 없이는 판별용 특징이 안 나옵니다.

4. CLIP 은 투영층을 태우면 오히려 나빠집니다 (0.5723 -> 0.5076).
   혹시 CLIP 을 쓰신다면 투영 전 특징을 쓰세요.


================================================================
채점 공식 확인 완료
================================================================

"DINO Component = 프레임 단위 코사인 거리" 가 맞습니다.
대회 평가 페이지 원문으로 확인했습니다.

    Score = 0.3 x DINO Component + 0.3 x Video Feature Component
            + 0.4 x Action Component

    DINO Component
      "생성 영상의 프레임 단위 시각적 특징이 정답 데이터와 얼마나 유사한지 평가"

    계산 방식
      "공식 제출킷(submission_kit)을 통해 추출된 feature 를 바탕으로
       정답 feature 와의 거리를 계산(Cosine Distance)합니다"

프레임 단위인 것도, 코사인 거리인 것도 공지와 일치합니다.
따라서 저희가 세운 비교 기준이 옳고, 결론이 그대로 유효합니다.

(프레임별 값을 어떻게 합치는지는 공지에 없지만, 단조 증가하는 방식이면
 어떤 것이든 모델 순위는 바뀌지 않습니다.)
